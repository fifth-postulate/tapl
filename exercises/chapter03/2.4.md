# 3.2.4

> How many elements does $S_{3}$ have?

## Proof
The sequence of set $S_{i}$ for $i\in N$ is defined as

$$
S_{0} = \varnothing
$$

and

$$
S_{i+1}
  = \{true, false, O\}
  \cup \{succ t, pred t, iszero t |t\in S_{i}\}
  \cup \{if t_{1} then t_{2} else t_{3} |t_{1},t_{2},t_{3}\in S_{i}\}
$$

Let $T_{i} = \#S_{i}$. Then $T_{0}=0$ and

$$
T_{i+1} = 3 + 3\cdot T_{i} + T_{i}^{3}
$$

The sequence starts with $0, 3, 39, 59439, \ldots$.

So there are 59439 elements in $S_{3}$.
