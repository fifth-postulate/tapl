# 3.5.18

> Suppose we want to change the evaluation strategy of our language so that the
> `then` and `else` branches of an `if` expression are evaluated (in that order)
> _before_ the guard is evaluated. Show how the evaluation rules need to change
> to achieve this effect.

## Answer

```plain
if true then v1 else v2 -> v1
```
  
```plain
if false then v1 else v2 -> v2
```

```plain
t2 -> t2'
--------
if t1 then t2 else t3 -> if t1 then t2' else t3
```

```plain
t3 -> t3'
--------
if t1 then v2 else t3 -> if t1 then v2 else t3'
```

```plain
t1 -> t1'
--------
if t1 then v2 else v2 -> if t1' then v2 else v3
```
