# 3.2.5

> Show that the sets $S_{i}$ are *cumulative*; that is, that for each $i$ we
> have $S_{i}\subset S_{i+1}$.

## Proof

Call $k$ frivolous if $S_{k}\subset S_{k+1}$. We will show that all numbers
are frivolous.

Since $S_{0}=\varnothing$ and $\varnothing\subset A$ for any set $A$, in
particular $S_{1}$, we see that 0 is frivolous.

Assume that $k$ is frivolous. We will show that $k+1$ is frivolous as well.
Let $s\in S_{k+1}$. There are three cases to consider

* $s\in \{true, false, 0\}$. By definition $s\in S_{k+2}.
* $s\in \{succ t, pred t, iszero t |t\in S_{k}\}. Since $k$ is frivolous, i.e
  $S_{k}\subset S_{k+1}$, we see that

$$
\{succ t, pred t, iszero t|t\in S_{k}\}
\subset \{succ t, pred t, iszero t|t\in S_{k+1}\}
\subset S_{k+2}
$$

* $s\in \{if t_{1} then t_{2} else t_{3}|t_{1},t_{2},t_{3}\in S_{k}\}. Since
  $k$ is frivolous, i.e. $S_{k}\subset S_{k+1}$, we see that
  
$$
\{if t_{1} then t_{2} else t_{3}|t_{1},t_{2},t_{3}\in S_{k}\}
\subset \{if t_{1} then t_{2} else t_{3}|t_{1},t_{2},t_{3}\in S_{k+1}\}
\subset S_{k+2}
$$

In all cases $s\in S_{k+2}$, hence $k+1$ is frivolous.

By the principle of mathematical induction all numbers are frivolous.
